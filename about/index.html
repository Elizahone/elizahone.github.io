本站由 Hugo 生成，托管于 GitHub Pages。主题 fork 自 Yihui Xie 的 hugo-xmin，但经过大量修改，已经和原版很不一样了——从配色、字体到文章页结构都重新做过。下面记录当前的样子，方便以后自己查阅。

主题：纸与墨

现在的样式取自一篇论文的排版：暖白的纸色背景 #fdfcfa、墨色正文 #1a1a1a、棕色强调色 #8a5a2b。正文使用中文衬线字体（Noto Serif SC，回退到宋体 / 思源宋体），界面元素用无衬线体，代码用等宽体。标题带细线分隔，长文章自动生成双栏目录，表格与引文统一成纸面风格。

导航菜单右侧的月亮/太阳按钮可切换夜间模式：夜间采用暖调的深灰底 #1c1b19 与米色文字，强调色也更亮一些。选择会记在浏览器的 localStorage 里，下次打开自动沿用；首次访问时跟随系统的「深色模式」偏好。

写文章

在 content/post/ 下新建 Markdown 文件即可。除了标准的 title、date 之外，还支持几个可选字段：

---
title: "文章标题"
date: 2026-11-23
subtitle: "一行简短的副标题"   # 可选，斜体显示在标题下
related:                       # 可选，文末「延伸阅读」；填其他文章的 slug
  - games101-normal-tranform
disableTOC: true               # 可选，隐藏自动目录
---

数学公式沿用原来的 KaTeX 配置：行内用 $...$ 或 \(...\)，块级用 $$...$$ 或 \[...\]。

代码结构

与主题相关的改动集中在 themes/hugo-xmin/ 下：

  • static/css/style.css —— 全部视觉样式。
  • static/css/fonts.css、layouts/_partials/head_custom.html —— 字体加载与 Google Fonts 链接。
  • layouts/single.html —— 文章页：副标题、目录、延伸阅读。
  • layouts/_partials/header.html —— 页面头部，并预留了文章级 custom.css 的加载钩子。
  • static/img/github.svg —— 首页的 GitHub 图标（本地文件，避免外链失效）。

构建与部署

本地预览：

hugo server

main 分支每次推送都会触发 .github/workflows/hugo.yml，用 hugo --gc --minify 构建后部署到 elizahone/elizahone.github.io。
